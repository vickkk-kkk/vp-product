# 支持状态

状态针对 **PrivateVP 整合后的产品**，不是上游项目能力清单。已有组件测试按精确代码身份登记；尚未登记不代表旧工作不存在，也不代表产品验收已经完成。

## 组件与平台

| 范围 | 已知基础 | 产品目标 | 当前产品验收 |
| --- | --- | --- | --- |
| Windows / Linux 桌面客户端 | vpn-parser 的 Rust / egui 源码基础 | 统一多引擎 UI、独立适配与生命周期 | 待 fork 构建与各平台实测 |
| macOS 桌面客户端 | 选定 Rust / egui 技术路线 | 与其他桌面端保持一致的业务行为 | 待平台集成与实测 |
| Android 客户端 | 共享 Rust 层抽取方向已确定 | 原生 VPN 生命周期与多引擎接入 | 待完整集成；不能以桌面测试替代 |
| iOS 客户端 | 共享 Rust 层抽取方向已确定 | 原生隧道扩展与多引擎接入 | 待平台环境、签名条件与完整验收 |
| Linux 服务端 | 已有管理服务、控制层、核心适配与候选实现 | vp_core 服务端及可靠生命周期 | 已纳入源码，待新目录完整构建与回归；非生产部署承诺 |
| Web 管理端 | 已有 Flutter Web 管理源码 | 通过管理 API 配置与观察服务端 | 已纳入源码，待新目录构建与联调 |
| 安装 / 升级 | 已有本地 bundle 工具与不同版本流程 | 可核验、可恢复的 Linux 交付 | 不同 bundle 流程需分别验收 |

## 客户端引擎

| 引擎 | 角色 | 新 fork 中的验收状态 |
| --- | --- | --- |
| vp_core | 优先接入 | 待逐平台接入与真实流量验收 |
| sing-box | 显式独立适配 | 待逐平台验收 |
| Mihomo | 显式独立适配 | 待逐平台验收 |
| Xray | 显式独立适配 | 待逐平台验收 |
| Shoes | 显式独立适配 | 待逐平台验收 |
| Meow | 显式独立适配 | 待逐平台验收 |

“计划支持”不是“已支持”。上游已有集成、独立引擎实验、版本探测和接口注册都不自动转换成新 fork 的产品通过记录。服务端的引擎边界仍为 vp_core，不随客户端多引擎目标扩大。

每个引擎 / OS 组合须单独覆盖：配置合法性、真实 TCP/UDP 流量、切换、停止后资源释放、后台行为与失败恢复。还要记录不支持的协议、模式和系统版本；不能用另一个引擎的结果填补。

## 已有验证的准确范围

客户端共享业务层的 18 个纯逻辑测试已在字节一致的独立源码快照中通过；这不是完整 fork 构建，也不是当前 submodule 基线已包含这些改造。尚无新客户端移动端构建或 VPN 生命周期通过结论。主仓源码归集的静态检查与合成测试见 [当前快照](source-snapshot.md)。
