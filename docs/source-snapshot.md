## 核心源码重建是构建前提

`integration/vp_core/` 不随源码提交。必须按 `core-lock.json` 固定的上游身份、有序补丁与结果身份重建；参见 [核心重建说明](../tools/core/README.md)。即使可选 feature 未启用，Cargo 也可能要求这些 path 依赖先存在。不能将缺失依赖误判为无需核心源码，也不能以复制开发机缓存代替重建。
